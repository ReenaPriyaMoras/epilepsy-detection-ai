# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The EpiDetect AI team takes the security of our application and patient data privacy seriously.

If you believe you have discovered a vulnerability, security flaw, or sensitive data leak:
1. **Do not** create a public GitHub issue.
2. Email details directly to the project maintainers.
3. Include clear steps to reproduce, affected endpoints, and suggested remediation.

We aim to acknowledge receipt of vulnerability reports within 48 hours and provide a timeline for patch release.
